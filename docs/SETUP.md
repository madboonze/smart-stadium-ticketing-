# Setup checklist

1. Install JDK 21.
2. Install Maven 3.9 or later.
3. Install Git.
4. Open this folder in IntelliJ IDEA as a Maven project.
5. Wait for Maven dependency resolution.
6. Run `SmartStadiumApplication`.
7. Visit `http://localhost:8080/api/health`.
8. Visit `http://localhost:8080/api/demo/stadium`.

If Maven is not installed but IntelliJ has Maven support, use the Maven tool window to run `spring-boot:run` and `test`.
